# 레시피 공공데이터셋 검증 결과

- 검증일: 2026-08-28 (KST)
- 대상: 식품의약품안전처 `COOKRCP01`, 농림수산식품교육문화정보원 레시피 기본/재료/과정정보
- 범위: 후보 데이터 검증만 수행. importer, 데이터베이스 스키마, 시드 코드는 변경하지 않음.

## 결론

대표 집밥 20개 시드의 **조건부 1차 소스는 농림수산식품교육문화정보원 데이터**로 정한다. 정확한 메뉴명 매칭이 13/20(65%)이고, 유사명까지 포함하면 18/20(90%)이다. 재료명과 용량이 별도 필드이며 조리시간, 난이도, 인분 수, 요리 분류가 전체 537건에서 모두 채워져 있어 이번 슬라이스의 정본으로 쓰기 가장 쉽다.

`COOKRCP01`은 **영양정보·이미지·저염 변형 레시피 보완 소스**로 사용한다. 유사명을 포함한 커버리지는 16/20(80%)이지만 정확명은 1/20(5%)뿐이고, 자유 텍스트 재료에 그룹명이 섞인다. 같은 메뉴의 재료를 두 소스에서 필드 단위로 합치지 말고, 농림수산 레시피 한 건을 정본으로 선택한 뒤 의미가 같은 경우에만 COOKRCP01의 영양·이미지 필드를 보완한다.

단, 농림수산 데이터는 data.go.kr의 `이용허락범위 제한 없음`과 제공기관 페이지의 `저작권표시+동일조건변경허락` 표기가 충돌한다. 제공기관 확인 전에는 더 엄격한 조건을 적용해 출처를 표기하고, 상업 배포용 시드 적재는 라이선스 확인을 완료한 뒤 진행한다.

## 농림수산 필드 완성도

기본정보 전체 537건과 이번에 선택한 18건 모두에서 조리시간, 난이도, 인분 수, 요리 분류가 100% 채워져 있었다. 예시는 `30분`, `초보환영`/`보통`, `4인분`처럼 들어온다. 결측 관점에서는 `timeMinutes`와 `difficulty`의 신뢰 가능한 소스로 쓸 수 있다. 다만 값의 현실성까지 외부 기준과 대조한 것은 아니므로 적재 시 형식 정규화와 범위 검사는 남겨야 한다.

별도 재료정보에서는 선택 레시피 18건의 208개 재료 행 모두 `재료명`과 `재료용량`이 분리되어 있었다. `재료타입명`도 제공된다. 다만 `1/2모`, `200g`, `약간`처럼 수량과 단위는 `재료용량` 한 필드에 합쳐져 있어 가벼운 용량 파서는 필요하다. 원천 오탈자(`돼기고기`)도 관측되어 이름 정규화 사전과 원문 보존이 필요하다.

## 두 데이터셋 교차 검증

두 소스 모두에서 대표 후보를 고를 수 있었던 메뉴는 15개다. 정규화한 재료명 집합의 Jaccard 유사도는 콩나물밥 0.412, 시금치나물 0.250, 된장찌개 0.227, 계란찜 0.214였고, 수제비는 0이었다. 김치찌개 0.059, 고등어구이 0.053, 장조림 0.050처럼 낮은 사례도 많았다.

낮은 유사도는 파서 오염뿐 아니라 실제 레시피 버전 차이가 크다는 뜻이다. 예를 들어 된장찌개 비교는 COOKRCP01의 `부대된장찌개`와 농림수산의 일반 `된장찌개`, 수제비는 `들깨곤약수제비`와 `감자수제비`다. 따라서 재료 목록을 합집합으로 병합하면 하나의 레시피가 아니라 서로 다른 두 조리법을 섞게 된다.

## 라이선스와 이용조건

- COOKRCP01 data.go.kr 페이지: 무료, 이용허락범위 `제한 없음`. 출처 의무가 별도로 명시되지는 않지만 데이터 계보 관리를 위해 식품의약품안전처와 서비스명을 저장한다.
- 농림수산 3개 data.go.kr 페이지: 무료, 이용허락범위 `제한 없음`.
- 농림수산 제공기관 상세 페이지: `저작권표시+동일조건변경허락`으로 표시되어 data.go.kr와 충돌한다. 상업적 이용 금지 표시는 확인되지 않았지만, 출처표시·동일조건 의무의 적용 여부를 제공기관에 확인하기 전에는 상업 배포 가능성을 확정하지 않는다.

## 채택 결정과 다음 단계 입력

1. **조건부 1차 소스:** 농림수산 기본정보 + 재료정보 + 과정정보. 제목, 재료, 조리과정, 조리시간, 난이도, 인분 수, 분류의 정본으로 사용한다.
2. **보완 소스:** COOKRCP01. 동일한 메뉴 버전임을 확인한 레코드에 한해 영양정보와 이미지를 보완하고, 저염 변형은 별도 레시피로 유지한다.
3. **수동 큐레이션:** 간장계란밥은 직접 작성한다. 닭볶음탕과 유사명 5건은 대표성 검토 후 확정한다.
4. **적재 전 차단 조건:** 농림수산 라이선스 표기 충돌을 제공기관에 확인한다. 확인 전에는 원천 URL·기관·레시피 ID를 보존하고 출처를 표시한다.
5. **파서 설계 입력:** COOKRCP01을 파싱할 때는 3.4%를 완성도 추정치가 아니라 자동 탐지된 최소 실패율로 사용하고, 그룹 헤더와 소스 섹션을 우선 예외 처리한다.
